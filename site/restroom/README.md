# Restroom — example output files

These files predict gallery ID i for query i. They illustrate the format only;
they are not ground truth or baseline model predictions. In NPY, positions follow
numeric query order 1.png, 2.png, ...; gallery IDs start at 1.

Public/A: submission_a.npy (10,); Private/B: submission_b.npy (30,).
The ZIP contains both files. CSV query_id,gallery_id may be reordered.

Task and baseline: https://github.com/IOAI-official/IOAI-2025/blob/main/Individual-Contest/Restroom/Restroom.ipynb
Image data: https://www.kaggle.com/datasets/hittungtran/restroom-ioai-2025
Official data attribution: IOAI 2025. Kaggle image dataset declares CC BY-NC-SA 4.0.
This directory contains no images or answer arrays.
