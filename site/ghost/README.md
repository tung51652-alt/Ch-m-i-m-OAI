# Ghost of the Machine — practice data

Source: https://huggingface.co/datasets/IOAI-official/ioai-2026-ghost-of-the-machine
Task/statement/baseline: https://github.com/IOAI-official/IOAI-2026/tree/main/Individual-Contest/5_Ghost_of_Machine
License: CC BY 4.0.
Proposed by Alexander D'yakonov and Nurdaulet Akhanov; developed by Nurdaulet Akhanov and Kirill Fedyanin.
Published by the IOAI 2026 Scientific Committee.

This practice package preserves original JSONL inputs. The leaderboard A/B answers
are omitted. In this grader Public = A, Private = B. Run your model separately on
each private/test_leaderboard_*/data.jsonl, export answers.jsonl and upload it to
the matching split. Notebook execution is not part of this website.
Boundary indices count Unicode code points as in Python len(text).
The sample submissions predict 0; they demonstrate the schema, not a useful model.
