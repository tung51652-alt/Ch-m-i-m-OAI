Cách nộp bài

  1. Bấm Nộp bài (cần đăng nhập GitHub), chọn tác vụ và tập đánh giá.
  2. Kéo thả file .csv hoặc .zip (chứa submission.csv/output.csv) vào ô File submission, chờ upload xong rồi bấm Submit.
  3. Sau ~1 phút bot comment điểm vào issue; bảng xếp hạng cập nhật sau đó ~1 phút.

Schema: DeepWeeds image_id,label · Spam Review id,label · ViLexNorm id,normalized. Xếp hạng theo điểm tốt nhất trên Private Test (ViLexNorm: Test Set); hòa thì so Public, rồi đến đội đạt điểm sớm hơn.
